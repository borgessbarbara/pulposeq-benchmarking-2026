# Fig. 1 panels (LongBench)

`07_fig1_panels.R` draws Fig. 1 b-i, one file per panel (`figures/fig1_panels/`), and writes the
numbers behind them (`results/figure_tables/`). Needs `spike-ins/` 01 and 02,
`unique_intron_chains/` 03 and 04, and `read-support/` 05.
Sequin panels and tables use the primary analysis only (`count_mode = "divided"`).
