# pulposeqBenchmarking2026
Collection of the [integrativebioinformatics/pulposeq](https://github.com/integrativebioinformatics/pulposeq.git) workflow integration and benchmarking for isoform-level analysis of bulk long-read RNA-seq public datasets. We evaluated pipeline runs across the bulk PacBio, ONT cDNA, ONT direct RNA-seq datasets.

## Datasets
### LongBench (2025)
From the [LongBench](https://github.com/mritchielab/LongBench.io) sequencing of  Human LUAD/NSCLC (Lung Adenocarcinoma or Non-small cell lung cancer), SCLC-A (Small Cell Lung Cancer Subtype A)  and SCLC-P (Subtype P) cell lines.

Sequencing data are available from Gene Expression Omnibus under accession number GSE303762 and [AWS S3](https://registry.opendata.aws/longbench/).

You can directly browse and download individual files using the [LongBench data browser](https://mritchielab.github.io/LongBench.io/browse-data/).

You, Y. et al. Benchmarking long-read RNA-sequencing technologies with LongBench: a cross-platform reference dataset profiling cancer cell lines with bulk and single-cell approaches. bioRxiv; 2025.  [https://doi.org/10.1101/2025.09.11.675724]().

## Dong _et al. (2023)_

ONT cDNA sequencing of Human LUAD (Non-small cell Lung Adenocarcinoma) cell-lines. RNA-seq data are available from Gene Expression Omnibus (GEO) under accession numbers GSE172421.Their pipeline is available at [XueyiDong/LongReadBenchmark](https://github.com/XueyiDong/LongReadBenchmark). 

Dong, X., Du, M.R.M., Gouil, Q. et al. Benchmarking long-read RNA-sequencing analysis tools using in silico mixtures. Nat Methods 20, 1810–1821 (2023). https://doi.org/10.1038/s41592-023-02026-3
