Supplementary Table 4 | Novel transcript models grouped by unique junction chain (UJC). Unit: UJC entities - one row per distinct intron chain, not per model. A UJC is defined by junctions alone, so MONO-EXON MODELS CARRY NO UJC AND ARE NEVER MATCHED; each is reported as protocol-exclusive. Transcript ends are not part of the match (see ST6).

Supplementary Table 5 | Agreement between protocols on the classification of the same unique junction chain. Unit: UJC entities reconstructed by >=2 protocols. An entity is concordant when every protocol that reconstructed it assigned the same value. Entities for which no protocol assigned a reference host gene are excluded from that row. Intervals are Wilson 95% - several rates rest on fewer than ten events and the interval, not the point estimate, is the result.

Supplementary Table 6 | Transcript-end differences between protocols reconstructing an identical intron chain. Unit: PROTOCOL PAIRS - an entity found by all three contributes three rows, so the totals here exceed the entity counts in ST4-ST5. Because the intron chain is identical by construction, every difference is terminal-exon extent, and spliced_2 - spliced_1 = d5 + d3 exactly. |delta spliced| is therefore largely redundant with |d3| and is given for completeness.

Supplementary Table 7 | Every classification disagreement between protocols, itemised. Unit: PROTOCOL PAIRS. d5 > 0 means protocol 2 reaches further upstream; d3 > 0 means it reaches further downstream. 'Likely driver' for biotype distinguishes a change of reference host gene, a crossing of the 500 nt lncRNA minimum, and a coding-potential flip at constant host; for the other attributes it names the end with the larger absolute difference. These are inferences from the coordinates, not from re-running the classifier.
